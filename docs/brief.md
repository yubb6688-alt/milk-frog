# 奶蛙官网落地页 Brief

- **名称：** 奶蛙
- **一句话定位：** 陪你工作，也陪你聊天的 Mac 桌宠。
- **页面目标：** 让第一次看到奶蛙的人了解它的真实互动方式、使用条件和聊天配置，再决定是否下载。
- **核对依据：** 2026-10-19 阅读本地项目代码，基于提交 `cd85344`。以下功能清单描述当前实现；用户画像是用于页面设计的假设，并非真实访谈或使用数据。

## 当前真正实现的功能

| 功能 | 当前行为与使用边界 | 代码依据 |
|---|---|---|
| 透明桌面陪伴 | 使用 200×200 的透明悬浮窗口，循环播放待机动画，素材按比例绘制。 | `Sources/main.swift`、`Sources/IdleAnimation.swift` |
| 定时走动与探头 | 正常待机约 30 秒后随机向左或向右走一段，再返回；走出屏幕时会从边缘探头。输入陪伴、拖动等互动会调整走动安排，并非固定每 30 秒必走。 | `Sources/Wandering.swift`、`Sources/main.swift` |
| 点击与拖动 | 点击时举手再放下；按住时呈现惊讶、举手和轻微挣扎，拖动可改变位置，松手后以新位置为走动返回点。 | `Sources/IdleAnimation.swift`、`Sources/HandRaise.swift`、`Sources/Dragging.swift` |
| 输入陪伴 | 检测到受支持的可编辑输入框后坐下拿出电脑，随按键交替敲击键盘；停止打字约 1.2 秒、输入框仍聚焦时，切换为手指贴脸的思考姿势。走动时可就地开始，位于屏幕外时先走回可见区域。 | `Sources/InputActivityMonitor.swift`、`Sources/TypingCompanion.swift`、`Sources/main.swift` |
| 打招呼 | 原生右键菜单中的“打招呼”会显示“呱呱呱”气泡。 | `Sources/IdleAnimation.swift`、`Sources/main.swift` |
| 暂停、继续与退出 | 原生右键菜单可暂停或继续桌宠动画，并同步暂停提醒动画计时；也可退出整个应用。此开关不是停止 AI 回复的开关。 | `Sources/AnimationClock.swift`、`Sources/IdleAnimation.swift`、`Sources/MessageReminder.swift` |
| 消息提醒演示 | 从应用菜单手动触发，显示头顶气泡、开心表情和撒花动作，正常播放约 6 秒后收起；尚未接入微信、邮件或系统通知。 | `Sources/main.swift`、`Sources/MessageReminder.swift` |
| DeepSeek 聊天 | 右键打开独立聊天窗口，联网请求 AI，逐字显示回复，可停止生成；支持回车发送、Shift + 回车换行。成功完成的对话会作为后续上下文；关闭窗口后重新打开仍保留本次运行的记录，退出应用后不保存聊天记录。 | `Sources/ChatWindow.swift`、`Sources/ChatSession.swift`、`Sources/DeepSeek.swift` |
| 本地聊天设置 | 可填写并保存 API key、模型名称和 HTTPS 接口地址；未配置时提示先配置并保留输入内容，遇到网络、密钥或额度问题会显示错误提示。 | `Sources/ChatSettings.swift`、`Sources/DeepSeek.swift` |

## 用户画像一：长时间在 Mac 上写东西的人

- **什么样的人：** 经常用 Mac 写方案、文案或学习笔记，喜欢可爱桌面元素，也希望能自行控制它何时活动。
- **什么时候、什么场景用它：** 独自工作或学习时，把奶蛙放在屏幕边角；输入文字时看它一起敲键盘，短暂停顿时看它进入思考动作。
- **他现在卡在哪：** 长时间面对文档的体验比较单调，静态壁纸缺少回应；需要专心时，又不希望桌面动画一直动。
- **他想要什么结果：** 获得一点随输入动作变化的陪伴感，想互动时点一下、拖一下，需要安静时可以暂停。

## 用户画像二：喜欢桌面个性化，也想随手聊两句的人

- **什么样的人：** 使用 Mac，喜欢有性格的小工具，愿意按照说明配置自己的 DeepSeek API key。
- **什么时候、什么场景用它：** 工作间隙或日常用电脑时，看看奶蛙走动探头；想问一个小问题或聊几句时，从右键菜单打开聊天窗口。
- **他现在卡在哪：** 单纯播放动画的桌宠互动有限；看到 AI 功能时，也不清楚是否需要自己的密钥、联网或额外配置。
- **他想要什么结果：** 既有可以点击、拖动的桌面角色，也能发起真实 AI 对话，并在下载前清楚知道配置要求和数据去向。

## 页面需要交代的使用条件

- **平台：** 当前是 Mac 应用；分发脚本生成 macOS 12 及以上的 Apple 芯片／Intel 通用安装包。此前已验证 Apple 芯片启动，Intel 尚未实机验证，不写“所有 Mac 均已测试”。
- **首次打开：** 当前分享版使用本地临时签名，尚未完成 Apple Developer ID 签名和公证，首次打开可能需要在系统安全设置中确认。
- **输入陪伴与隐私：** 输入联动只检查输入控件信息和按键活动，不读取输入文本，排除密码输入框；不能宣传为“无需权限”或“识别所有软件输入框”。
- **聊天与隐私：** API 配置保存在用户自己的 Mac，文件权限限制为当前用户读写，但密钥未加密保存。发起聊天时，会向所配置的服务发送认证密钥、主动输入的问题及有效会话上下文；不能宣传为“AI 完全离线”或“聊天内容不离开电脑”。
- **提醒边界：** 消息提醒目前只支持手动演示，不写成“自动接收微信或邮件消息”。
- **文案依据：** 不虚构用户数量、好评率、效率提升或用户评价，不承诺长期记忆、自动任务执行等未实现能力。
