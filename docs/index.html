01 / 桌面上的小日常

你忙你的，
它有它的小动作。

从认真敲键盘，到偷偷探出脑袋。
不用专门腾出时间，奶蛙就在旁边。

01

你打字，它也开工

点击输入框，奶蛙坐下拿出电脑。双手随着你的按键交替敲打；停下来时，它也手指贴着脸，想一想。

打字陪伴 / 停顿思考
02

走一走，探个头

待机一会儿，就向左或向右走走，再回到原点。跑到屏幕外，还会俏皮地探出脑袋。

左右散步 / 屏幕边缘探头
03

点一下，把它抱走

点点奶蛙，看它把手举起来。按住时会惊讶地小小挣扎，你可以把它拖到喜欢的位置。

点击举手 / 按住拖动

想安静一会儿？右键就能暂停动画。输入陪伴需开启辅助功能权限，并使用系统能识别的输入框。

02 / 有话，慢慢说

不只在旁边，
也能接住你的话。

右键奶蛙，打开聊天窗口。接入 DeepSeek 后，发一个问题，或分享今天的小事，看回答一个字一个字地出现。

真实 AI 回复逐字显示随时停止回复

也可以右键选「打招呼」，收获一句“呱呱呱”。
应用菜单还有气泡与撒花的手动提醒演示，尚未接入微信、邮件或系统通知。

和奶蛙聊聊天操作示意 · 非截图

“慢慢说，蛙蛙在呢。”

  1. 1右键选择「聊天」，打开独立窗口。
  2. 2在「设置」中填写自己的 API key、模型名称与接口地址。
  3. 3输入问题，回车发送。回复逐字出现，也可以点击「停止」。
需要联网及可用 API 额度；退出应用后不保留聊天记录。

03 / 让奶蛙住进你的 Mac

准备好桌面，
剩下的很简单。

目前为内测分享版。
拿到安装包后，按这三步开始。

STEP 01

拖进「应用程序」

双击 .dmg 安装包，将奶蛙拖到 Applications 文件夹，再从「应用程序」中打开。

STEP 02

开启输入陪伴

在奶蛙应用菜单中选择「启用输入陪伴」，按提示开启系统辅助功能权限。若未生效，退出奶蛙后重新打开。

STEP 03

想聊天，再配一下

右键 → 聊天 → 设置。填入你自己的 DeepSeek API key、可用模型名称，以及接口地址 https://api.deepseek.com，保存后就能发送问题。

第一次打开请留意：当前分享版尚未经过 Apple 开发者签名和公证。若系统拦截，在确认安装包来源可信后，可前往「系统设置 → 隐私与安全性」找到「仍要打开」；macOS 12 对应「系统偏好设置 → 安全性与隐私」。公司设备如受限制，请联系管理员。

04 / 下载前，你可能想知道

把使用条件，
也说清楚。

一点桌面陪伴，也需要清楚的边界。

我的 Mac 能用吗？

安装包面向 macOS 12 及以上，包含 Apple 芯片与 Intel 两种架构。Apple 芯片已验证启动，Intel 版本已编译但尚未实机验证。

输入陪伴会读取我打的字吗？

输入陪伴只检测输入控件信息和按键活动，不读取输入文本，并排除密码框。跨应用联动需要辅助功能权限；无法保证识别每个软件的所有输入框。

聊天内容和 API key 保存在哪里？

API 配置保存在你自己的 Mac，文件权限限制为当前用户读写，密钥未加密保存。聊天时，认证密钥、主动发送的问题和有效会话上下文会发往所配置的服务。聊天记录只在本次运行中保留，AI 回复需要联网。

没有 API key，也能养奶蛙吗？

可以使用待机、走动、拖动、打招呼等桌宠功能；输入陪伴需要相应系统权限。只有 AI 聊天需要自行配置 API key 与可用额度，未配置时会提示先设置。

它会自动提醒微信或邮件消息吗？

目前不会。现有提醒是从奶蛙应用菜单手动触发的演示，会显示头顶气泡、开心表情和撒花动作。
