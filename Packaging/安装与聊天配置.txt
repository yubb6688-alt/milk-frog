奶蛙 · Mac 安装与聊天配置

适用系统
macOS 12 Monterey 或更新版本。安装包同时包含 Apple 芯片（M 系列）与 Intel 版本。
Intel 版本已交叉编译和检查，但尚未在 Intel 实机上验证。

安装
1. 双击“奶蛙-0.1.0-macOS-universal.dmg”。
2. 将“奶蛙.app”拖到旁边的“Applications（应用程序）”文件夹。
3. 从“应用程序”中打开奶蛙；不要一直从安装盘运行。
4. 安装完成后，可在访达中推出“奶蛙安装”磁盘。
更新旧版本前，请先从奶蛙的右键菜单退出，再替换应用程序中的旧版本。

首次打开可能出现系统提示
此分享版仅有本地临时签名，尚未经过 Apple Developer ID 签名和公证。
如果提示“无法验证开发者”或“Apple 无法检查是否包含恶意软件”：
确认收到的是可信同事提供的本安装包后，先尝试打开一次，再前往
“系统设置 → 隐私与安全性”，找到奶蛙对应的“仍要打开”，按系统提示确认。
macOS 12 对应“系统偏好设置 → 安全性与隐私 → 通用”。
如果公司设备不允许此操作，请联系管理员；不需要关闭系统安全保护。
Apple 官方说明：https://support.apple.com/zh-cn/102445

现有功能
• 200×200 透明桌宠、待机动画、定时左右走动返回和屏幕边缘探头。
• 按住拖动、惊讶挣扎和举手动作。
• 输入陪伴：点击可编辑输入框后坐下，随键盘输入打字，停下时思考。
• 原生右键菜单：打招呼、聊天、暂停/继续、退出。
• 演示消息提醒：应用菜单“奶蛙 → 演示消息提醒”，显示气泡、开心和撒花。
• DeepSeek 聊天：流式逐字显示、停止回复、当前窗口会话上下文。
提醒仍是手动演示，未连接微信、邮件等消息来源。聊天记录只在本次运行中保留。

启用同步打字动作
1. 打开奶蛙后，点击屏幕顶部菜单“奶蛙 → 启用输入陪伴…”。
2. 在“系统设置 → 隐私与安全性 → 辅助功能”里开启奶蛙。
   若列表中没有奶蛙，点“+”，选择“应用程序”中的奶蛙。
3. 如果动作仍未同步，退出奶蛙后重新打开。
此权限用于识别输入框和按键活动；输入陪伴不读取输入内容，密码输入框不参与。
不授予此权限也可以使用聊天、拖动和其他桌宠功能。
若以后更新后失效，可移除旧的奶蛙授权，再添加应用程序中的新版本。

配置 AI 聊天（同事需要自己的 API key）
1. 在 DeepSeek 开放平台 https://platform.deepseek.com/ 登录，创建自己的 API key。
   API 服务使用开放平台额度；网页聊天账号本身不等于已有 API 调用额度。
2. 右键奶蛙 → 聊天 → 右上角“设置”。
3. 填写：
   API key：自己在开放平台创建的密钥。
   模型名称：deepseek-flash
   接口地址：https://api.deepseek.com
   注意接口地址不是 https://chat.deepseek.com，模型名称不是昵称或账号名。
4. 点击“保存”，回到聊天窗口输入问题，回车发送。
   Shift + 回车换行；回复时“发送”按钮变成“停止”。
模型和接口地址均可在设置中修改，以 DeepSeek 官方文档和账号支持的模型为准：
https://api-docs.deepseek.com/

隐私与本地配置
本安装包不附带制作者的 API key、个人配置或聊天记录。
每位使用者的配置单独保存在自己 Mac 的：
~/Library/Application Support/MilkFrog/deepseek.local.json
这是本地配置文件，密钥不加密存储，文件权限为仅当前用户可读写（0600）。
不要转发此文件、截图泄露密钥，也不要放进 Git 或共享目录。
聊天会把你主动发送的消息和本次有效会话上下文发给所配置的 API 服务。
未配置 API key 时不会发送请求，会提示先配置。

常见问题
• “API key 无效或没有权限”：检查密钥是否正确、是否已撤销。
• “账户余额不足”：到 DeepSeek 开放平台检查额度。
• “请求配置不正确”：检查模型名称与 API 地址。
• “连接超时/连接中断”：检查网络后重新发送。
• 卸载：先退出奶蛙，再把应用程序中的奶蛙移到废纸篓。
  如需同时清除密钥，可删除上述 MilkFrog 本地配置文件夹。
